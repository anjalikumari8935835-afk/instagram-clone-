# Instagram Clone

A simple **Instagram Login Page Clone** built using **HTML5 and CSS3**. This project recreates the visual design of an Instagram-inspired login page as a front-end practice project.

## 📸 Preview

![Instagram Clone Banner](assets/instagram-clone-banner.png)

## ✨ Features

- Instagram-inspired login interface
- Username and password input fields
- Login button
- Forgot password option
- Facebook login button
- Create new account button
- Meta branding
- Instagram-style gradient text
- Three overlapping image cards
- Rotated image card design using CSS
- Font Awesome icons
- Clean and simple user interface

## 🛠️ Technologies Used

- **HTML5** — Structure of the webpage
- **CSS3** — Styling, layout, positioning, gradients, and design
- **Font Awesome 6** — Facebook and Meta icons
- **Unsplash** — Images used in the design

## 🚀 How to Run

### Using Browser

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

### Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Install the **Live Server** extension.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.

## 🖼️ Design

The page is divided into two main sections.

### Left Section

- Instagram logo
- Welcome message
- Gradient text
- Three overlapping image cards
- Rotated card effects

### Right Section

- Login heading
- Username input
- Password input
- Login button
- Forgot password button
- Facebook login option
- Create new account button
- Meta branding

## 🔗 External Resources

This project uses external resources:

- **Font Awesome CDN** — for Facebook and Meta icons
- **Unsplash** — for the image cards
- **Instagram CDN** — for the Instagram logo

An internet connection may be required for these external resources to load correctly.
